# W02-PC1 — GDM vs designer f(R) positive control

Status: **PASS_WITH_SCOPE**  
Frozen DSIR authority: `e3276e2193f6a5200b541a194e3175356ae5a1c1`

## Purpose

Calibrate the Wave-02 pairwise machinery on an already-controlled case where a restricted response summary looks nearly degenerate but fuller response information breaks the apparent equivalence.

## Frozen evidence inherited from Wave 01

For C3 GDM vs C5 designer f(R):

- leading scale-mode angle is only about `0.07813 deg` for GDM cs2 vs f(R);
- leading scale-mode angle is only about `0.10169 deg` for GDM cv2 vs f(R);
- corresponding time-mode angles are about `25.18 deg` and `25.49 deg`;
- full oriented response-ray angles are about `154.82 deg` and `154.51 deg`.

## Hard interpretation

A nearly identical restricted scale profile is not full-response equivalence. Time evolution and response orientation retain strong information that the leading scale mode alone discards.

This positive control supports W02-H1 and calibrates the rule that pairwise discrimination must use the smallest **sufficient** common response block rather than whichever one-dimensional summary looks most convenient.

## Scope caveat

These are theory-response geometry statements. They do not by themselves establish observational discrimination; covariance/operator projection remains a separate graph.
